# 初期画像を基準とする多視点生成 v16

目的は、広い構図の元画像の外観を維持しながら、カメラを移動しても一視点の画像を引き伸ばした形にならないこと。

1. プロンプトに部屋の奥の角から床・天井・三面の壁・主要家具を捉える構図を追加する。構図の達成を自動で保証するものではない。
2. 全体画像を観察して物体別メッシュと部屋構造を構築する。未観測面は推定。既存のSAM3D・配置推定を使用する。
3. 初期視点の参照画像には元画像をそのまま使う。別視点では投影色を初期案として利用するが、家具・構造面の画素を固定せず、深度ControlNetと元画像IP-Adapterで再生成する。構造面の平面性は深度で制約する。生成強度は0.75、再試行で0.65、0.55とする。
4. 学習用参照だけで各家具を少なくとも25cm離れ、物体を見込む角度が12度以上異なる二つの位置から観測できるか検査する。同じ位置からの回転や複製画像では合格しない。失敗したデータをGS学習用として完成扱いしない。
5. GSは全視点のRGBで学習する。構造面の深度重み0.2は維持し、家具の概形深度の重みを0.03にする。家具の表面距離許容を6cmから15cmへ緩め、配置の逸脱は引き続き抑える。新しい推定深度を形状の正解として上書きしない。

## 実行

```bash
./run.sh generate --prompt 'A cozy living room with a brown leather sofa, bookshelves filled with books and a wooden coffee table, warm daylight' --output runs/whole_room_v16 --size 512 --views 24 --seed 52
./run.sh train runs/whole_room_v16 --steps 3000 --max-points 180000
```

`<output>_scaffold/source_front.png` が元画像、`<output>_scaffold/scene_mesh.glb` が概形。
`<output>/references.html` が採用参照画像、`parallax_audit.json` が家具ごとの視差検査、`front_render.png` と `heldout_render_*.png` が実際のGS描画。
既存v15の結果・画像は変更しない。v15の生成途中データは設定が異なるためv16として再開できない。

## 限界と検証

別視点画像は独立した実写ではなく生成仮説。視差検査はカメラとメッシュの幾何的条件であり、画像内容の多視点整合性を証明しない。家具の再生成で見た目の不一致が増える可能性がある。深度エッジ・意味検査は継続するが保証ではない。
初期画像、概形のみの描画、生成参照画像、実GS描画を区別して比較する。固定した初期画像・概形でv15/v16を比較してから、部屋全体の初期画像を新たに生成する実験を行う。
