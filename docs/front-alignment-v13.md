# 正面画像とメッシュの再投影整合（2026-10-30）

## 参考にした研究と、実装した範囲

- **WorldMesh**：共通メッシュを外観生成の幾何基準にする方針と、補足資料のカメラ座標・世界座標を使う物体配置を参考にした。[論文・公式ページ](https://mschneider456.github.io/world-mesh/)。今回、補完画像の既知のカメラ方向を配置へ反映し、全ての家具が正面の壁へ集まる問題を修正した。
- **SAM 3D Objects**：形状だけでなく位置・回転・尺度を画像や点マップに合わせる考え方を参考にした。[原論文](https://arxiv.org/abs/2511.16624)、[公式実装](https://github.com/facebookresearch/sam-3d-objects)。今回の最適化器は独自のSciPy実装であり、SAM3D論文のtest-time optimizationを再現したものではない。復元済みのメッシュを再利用する。
- **MoGe-1**：導入済みの単眼幾何モデルから、点マップ・深度・画角を取得する。[公式実装](https://github.com/microsoft/MoGe)。使用モデルは `Ruicheng/moge-vitl`。最新のMoGe-2/3を使用したと解釈しない。相対的な尺度はカメラ高さ1.3mの事前仮定で補う。

## 従来の問題

SAM3Dメッシュを言語モデルの寸法へ合わせ、その後AABB衝突を避けるよう配置していた。ソファがL字などの凹形状でも外接箱全体を障害物とみなし、画像と大きく異なる位置へ動かすことがあった。画像カメラは固定の画角75度・室内原点を仮定していた。

## 変更

1. 切り出し画像に対するSAM3マスクを、余白とリサイズを逆変換して元の正面画像へ戻す。検出矩形全体を物体のシルエットとは扱わない。
2. 正面のMoGe点マップから、物体領域を除いた下部の点にRANSAC平面推定を適用する。床面を推定できた場合にだけ、カメラの傾きと相対奥行きの事前情報に使う。GS教師の深度には使用しない。
3. 実際の物体メッシュを再投影し、カメラの画角・高さ・前後位置・傾き、床置き家具のx/z位置・一様スケール・ヨー角を同時に最適化する。画像端で切れた物体の輪郭は片側の制約とする。
4. 家具の縦横比を歪めない。明示的な寸法指定はスケールを固定する。支持される小物は親の移動・回転・尺度に追従し、組み立て時の実支持面検査を通す。
5. 正面に見えなかった家具は、切り出し元の側面・背面カメラの方向と対応する壁へ配置する。画像補完の仮説であり実測の配置ではない。
6. 再配置後にAABB衝突回避を再実行して画像整合を壊さない。代わりに重なる箱の組を記録する。**凹メッシュ同士の厳密な非衝突を保証する検査は未実装**。
7. 調整したカメラと画角でRGB-D参照を描画する。GSの教師深度はこの共通メッシュへのレイ交差から得る。
8. 遮蔽を含む実際のメッシュ描画と元画像の可視マスクを比較する。平均シルエットIoUが0.4以上、各物体0.2以上を初期の工学的な検査条件とする。学術ベンチマークの閾値ではない。未通過・古いカメラ/メッシュ/元画像に対応する検査結果ではGS学習を停止する。

## 実行方法

旧出力を保持したまま、入力画像・単体メッシュ等だけを新フォルダへコピーして再配置する。

```bash
cd '/home/dpc7/world GS'
./run.sh refit-front runs/image_room_v12_20261028 --output runs/image_room_frontfit_new
./run.sh train runs/image_room_frontfit_new --steps 1000 --max-points 120000
```

今後の `generate --mode image-room` にも組み込んだ。生成方式の版を要求記録へ追加したため、旧v12フォルダへそのまま`--resume`して参照を上書きせず、上記`refit-front`で分離する。

## 保存する情報

- `front_pointmap.npz`：MoGeの正面幾何・カメラ推定。教師深度ではない。
- `front_alignment.json`：再投影誤差、画角・姿勢、矩形IoU、推測物体の配置、AABB衝突候補。
- `front_silhouette_audit.json`：遮蔽込みのシルエットIoU、検査結果、メッシュ/カメラの識別ハッシュ。
- `planning/aligned_scene_plan.json`：修正後の配置計画（新規実行時）。
- `scene_mesh.glb`, `references.html`, `scene_unity.ply`：修正後の基準メッシュ、GS教師一覧、学習後GS。

## 残る問題

正面の位置・大きさの一致を優先した変更である。密な輪郭やRGBを直接最適化しておらず、窓の復元、本棚内の本の欠落、材質の写り込みや周期模様は未改善。単眼画像からの実寸・不可視面には曖昧さが残る。今回の画角やカメラ位置は探索範囲の端に近く、真の撮影条件の復元を示すものではない。側面画像も3方向の独立した補完候補のままで、世界全体の画像を同時に整合させる方式ではない。
