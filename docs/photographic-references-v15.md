# メッシュ条件付き写真参照 → 3DGS（v15）

## 生成経路

既定の `photo-room` は次の順で動く。

1. プロンプトから部屋全体の正面画像を作る。
2. 側面・背面を推測し、室内画像から切り出した物体をSAM3Dで復元する。
3. 家具の配置と正面カメラを整合し、部屋全体の共通メッシュを作る。
4. メッシュ深度をControlNetへ、正面写真をIP-Adapterへ与え、写実的な参照画像を生成する。
5. 生成済みの学習視点から色を再投影する。遮蔽と深度の一致を確認し、見えている画素を保護して未知領域を補完する。
6. 形状・家具位置の検査を通過した参照だけで3DGSを学習する。深度教師は画像から再推定せず、共通メッシュの交差深度を使用する。

従来のメッシュ描画だけを使う経路は `--mode image-room` に残す。

## 実行

```bash
./run.sh generate --mode photo-room --prompt 'A cozy living room with a sofa, bookshelves and a wooden table, wide angle interior photograph' --output runs/photo_room_new --size 512 --views 12 --seed 52
./run.sh train runs/photo_room_new --steps 2000 --max-points 180000
```

初期の画像・メッシュ生成は同名の兄弟フォルダ `photo_room_new_scaffold` に保存する。最終的な参照画像とGSは `photo_room_new` に保存する。プロンプトのみから開始できる。

既存の正面画像・メッシュを再利用して、外観生成以降を比較する場合：

```bash
./run.sh synthesize-appearance runs/image_room_coverage_v14_20261030 --output runs/image_room_photo_v15d_20261030 --pilot-views 8
./run.sh synthesize-appearance runs/image_room_coverage_v14_20261030 --output runs/image_room_photo_v15d_20261030 --resume
./run.sh train runs/image_room_photo_v15d_20261030 --steps 2000 --max-points 180000
```

パイロットは未完成の診断出力であり、学習用scene.jsonを完成させない。`--resume` は同じ元画像・メッシュ・カメラ・生成設定の場合のみ可能。

## 外観モデルと共有

- Stable Diffusion 1.5 Inpainting + `lllyasviel/control_v11f1p_sd15_depth`。
- `h94/IP-Adapter` の `ip-adapter_sd15.bin`。元画像の参照強度0.2。
- 部屋を新しく作り替えないよう、画像変換の強度を0.6から開始し、再試行では0.5、0.4へ下げる。深度ControlNetの強度は1.2、1.5、1.8。
- 元画像の物体マスクとメッシュの物体IDが対応する画素を初期外観とする。本棚はフレームだけでなく内部の本を含む複合領域として扱う。
- 投影先のメッシュ点から既存画像へ逆投影し、深度が一致した画素だけ色を移す。画像境界・遮蔽境界を侵食して補完領域に戻す。
- 生成済み学習画像だけを共有キャッシュへ追加する。評価画像は学習画像の生成条件に使わない。
- 未知の床のガイドは固定画像切り抜きの家具混入を避け、木色を初期値とする。最終RGBは生成画像である。

汎用attention slicingはIP-Adapterのattention processorを置換してしまうため使わず、SDPAで動かす。

## 検査

1. Depth Anything V2 Smallで生成画像の相対逆深度を予測する。これは画像検査だけに使い、メッシュ・教師深度を置き換えない。
2. 生成領域と周囲3pxの深度境界再現率を検査する。512pxで許容距離10px。閾値は min(0.55, max(0.05, ガイド描画の境界再現率×0.9)) とする。正しいガイドでも深度推定器が検出できない境界に一律0.55を要求すると、無地の壁の隅を誤って不合格にするため、画像変換前の観測可能性で基準化する。全画像の境界再現率も診断値として記録する。
3. 生成した壁・床・天井の逆深度が平面に近いか検査する。元画像から引き継いだ画素は対象外とする。
4. GroundingDINOで、メッシュの位置に支持されないソファ・テーブル・本棚・椅子を検出する。椅子とソファは着座家具として位置支持を共有する。無地面全体、大部分が継承画素、またはガイド描画にも同位置で現れる検出は、新規物体の証拠とはせず診断に分ける。
5. 最大3回試し、不合格画像は学習へ入れない。黒い拒否画像も採用せず再試行する。安全判定は無効化しない。
6. 採用後に学習・評価の分割を観測付きで再選択する。採用した学習画像だけで、元の全予定カメラの面が観測されているか48pxの深度付き可視検査を行う。各視点の未観測率1%以下を要求し、物体ごとの複数視点検査も行う。不足する場合は、合格済み学習画像全体を共有して補完を追加する。評価画像はこの共有にも使わない。
7. RGB・カメラ・信頼度の検査記録を保存し、未完成または検査後に変更された参照は学習を拒否する。
8. GS学習後の被覆は、不合格RGBのカメラも含む全予定視点で検査する。写真参照ありのGS点数上限は30万。

閾値は独自の工学的な初期設定であり、研究の再現ベンチマークではない。物体検出の誤検出・見逃しや、深度推定の誤差は残る。

## 出力

- `source_front.png`: 元の正面画像。
- `scene_mesh.glb`: 形状の基準。
- `view_*.png`, `heldout_*.png`: 採用された写真参照。カメラ名が連番で欠ける場合は不採用画像がある。
- `appearance_candidates/`: ガイド、保護画素、再試行の生成画像。
- `appearance_records/`: 各視点の採用・不採用と理由。
- `appearance_audit.json`, `appearance_coverage.json`: 参照検査と全予定視点の可視検査。
- `references.html`: 採用した写真参照の一覧。
- `front_render.png`, `scene_unity.ply`: 学習後のGS。
- `all_view_coverage.json`, `gs_coverage_quality.json`: 全予定視点のGS被覆。

## 先行研究との関係と制約

[WorldMesh](https://arxiv.org/html/2603.22972v3)の共通メッシュを条件とする外観生成、画像検査、メッシュ深度を使うGS学習を参考にした。[LucidDreamer](https://luciddreamer-cvlab.github.io/)の既知領域の再投影とインペイントにも対応する構成である。画像条件付けは[Diffusers公式IP-Adapter](https://huggingface.co/docs/diffusers/using-diffusers/ip_adapter)を使用する。WorldMeshやFillerbusterの学習済みモデル・全アルゴリズムを再現したものではない。

この実験では既存の正面画像と4物体のメッシュを再利用する。初期入力の比較を固定して外観生成の効果を確認するためで、新規の家具・窓のメッシュを追加した実験ではない。未知の物体裏側、棚内部の本、窓の奥行きなどは保証しない。生成写真と共通メッシュは実世界の正解ではなく、独立した再構成精度・写実性の証明ではない。照明はGSの色に焼き込まれる。

## 今回の実行結果（2026-10-30）

`runs/image_room_photo_v15d_20261030` に、既存正面画像と4物体メッシュを再利用して出力した。新しい画像生成で合格した106参照を採用し、90視点を学習、16視点を評価に使用した。8画像は不採用。合格済み画像全体を使う追加補完により、元の114予定カメラに対する粗い可視検査の最悪未観測率は0.564236%となった。今回の最終分割では評価画像からの昇格は不要だった。

512px、3000ステップ、初期180000／最終243462ガウス。全114予定視点でのalpha<0.5の画素率は平均0.003229%、最悪0.284576%。これはメッシュへの被覆検査であり、写真らしさや独立した形状精度の評価ではない。正面シルエットIoUは0.654746。114テストが成功した。

実際のGS描画では、旧メッシュ教師で失われていた本・ラグ・窓・クッションの外観が復元される一方、ソファの輪郭や継ぎ目に歪みが残る。窓の開口・奥行きは追加復元しておらず、写真の外観が既存壁に載る。未知側の本棚は空の領域が残り、元のプロンプトの物体属性を完全には満たしていない。全周の無破綻や、添付例と同等の写実性を達成したとは評価しない。
