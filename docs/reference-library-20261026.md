# 参考画像に合わせた窓付き読書室（2026-10-26）

出力先：`runs/reference_library_window_20261026`。ユーザーの `livingroom_depth_seams_v5_final/front.png` を構成と外観の参考にした新規3Dシーン。

## 構成と入力

- 中央の白枠窓、窓の左右と側壁の本入り白本棚4台、茶革のソファ2台によるL字の座席、灰色のラグ、楕円ローテーブル、本の山、かご。
- 部屋6.4×2.9×6.2m。独立した家具・小物は10インスタンス。棚の中の本は本棚メッシュ・UVの一部で、1冊ずつの独立物体ではない。
- ローカルLLMは窓を家具扱いするなどの誤りで計画に失敗したため、今回の配置は参考画像を解釈した明示的な計画に切り替えた。`planner=assistant_reference_image_layout` として記録し、自動LLM計画の成功とは扱わない。
- 本棚・ソファの外観は built-in `image_gen` で参考画像から生成した単体画像を使用。画像はSAM3→SAM3Dへの入力であり、部屋に貼る板画像ではない。他の小物は既存のローカル画像生成を使用した。
- 共通の白本棚はSAM3Dで一度復元し、4台のインスタンスとして配置。本棚のメッシュ生成を手続き的な箱で代用しない。
- ソファの形状は2つの独立メッシュ。単一の一体型L字ソファや完全に継ぎ目のないコーナー形状を保証するものではない。

## 実装変更

- `window_geometry.py`：+z側の壁を4領域へ分割し、本物の矩形開口を設ける。窓枠と桟、外部の空背景と細い枝の幾何を追加する。
- `physical_render.py`：窓の外側から室内へ向く面光源、明るい屋外背景を追加。窓の枠も影を落とす。窓はガラスの反射・屈折を再現する機構ではなく、開口＋枠＋不透明な屋外背景である。
- `semantic_plan.py`：矩形の背面窓を `room.window={x,width,sill,height}` で検査。床ラグの薄さと、目線より下の家具をカメラの衝突と誤判定する問題に対応。
- `learned_scene.py`：薄いラグを床面に合わせる。ラグに限り厚さを12mmへ補正するため、全形状を一様スケールだけで処理するわけではない。任意の家具には適用しない。
- `asset_worker.py`：明示的な `reference_asset.png` がある場合はその画像を切り出しに使う。共通メッシュの `instance_of` を記録して再利用する。
- 既定の本棚画像は縦長構図を優先する。今回の最終本棚はそのローカル生成とは別の、参照付きbuilt-in生成画像である。
- 任意の `reference_camera={eye,target}` による正面構図を追加。室外・家具内のカメラを拒否する。
- GS学習後に `front_render.png` を保存する。`front.png` はメッシュ参照、`front_render.png` は実際のGS描画である。
- 構造検査は開口周囲の複数の共平面三角形にも対応。意図した開口がレイを通すこともテストする。

## 実行検証

- 参照118視点：学習99、検証19。
- 10物体はそれぞれ29〜63の学習視点で16画素以上見えている。
- 正面カメラ、窓の実開口、分割壁の平面性、ラグ、従来の配置・学習補助処理を含め85件の回帰テスト成功。
- GSは初期上限140,000点、3,000ステップ、学習中上限180,000点で実行。
- 3,000ステップの学習完了、最終180,000ガウス。`scene_unity.ply` は44,641,531バイトで保存。
- 検証19視点の平均相対深度誤差は約1.43%、RGB L1は約0.0182。不透明度0.5未満の欠落画素率は平均約0.089%、最大約1.55%。生成した基準メッシュに対する評価であり、実世界の正解や元参考画像の完全な再現を保証しない。
- 本の細部や表面にぼけがあり、ソファの継ぎ目・窓枠の接合部なども元画像とは異なる。室内の構成を参考にした近似である。
