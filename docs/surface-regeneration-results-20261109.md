# 概形修正・不足面補完を取り入れた再生成（2026年11月9日）

再生成、本学習、前回と同じ8視点での評価まで完了しました。初期参照画像、初期カメラ、家具の位置・大きさは維持しています。元の結果は上書きしていません。

## どこを変更したか

1. 左本棚を自身の中心周りに180度回し、開口が室内側を向くように修正。
2. 中央窓を初期画像に合わせて2列3段に変更。ランダムに作っていた窓外の枝を除去。
3. 初期画像の左窓を室内へ反映。元の部屋幅では左壁が画像の視野外になっていたため、家具を動かさず左壁をx=-3.0から約-2.399へ見直し、画像の窓検出とカメラの交点から開口を作成。室内寸法は推定であり実測ではありません。
4. 233カメラのうち36視点を、ソファ・左右本棚・テーブルの不足面を向く専用・代替視点へ変更。
5. 深度・遮蔽・物体IDが一致する範囲で、観測済みの画像をガイドへ引き継ぐ方式に変更。壁・天井への写真断片の固定をやめ、床とラグなど別の面への混入も防止。
6. 失敗した視点は乱数変更や代替カメラで再試行。失敗キャッシュの誤再利用を防ぎ、画像・メッシュ・設定の変更時は古い学習結果を再利用しない保護も追加。

- 正面では、左本棚の開口と本、中央窓の格子、左窓が確認できます。
- 前回欠損が大きかった本棚付近を含む、同じ8カメラからGSを描画しました。
- 8視点とも、修正メッシュが存在する画素におけるα<0.5の欠損率は0%。家具別の同じ指標も、今回記録した領域では0%でした。
- 修正メッシュへの平均深度AbsRelは0.01044。実世界の正解形状への誤差ではありません。
- 学習に使った233視点の同じ欠損率も0%でしたが、学習視点であることを明確に区別します。
- PLYのヘッダー、62属性、頂点数、バイナリの長さを確認済み。比較画像のリンク切れはなく、RGB教師の保存枚数も200枚を確認済み。
- コードの188件のテストが成功しました。

## 残っている問題

- 窓の近接描画にはにじみや歪み、壁には色むらが残ります。
- ソファの強い光沢や、初期画像の白いクッション・本・カップなどの見え方には差があります。初期画像の全小物を立体化する処理までは行っていません。
- α<0.5の欠損率0%は、今回の8視点・閾値に限った結果です。任意の移動範囲で穴がないことや、高い写実性を保証しません。
- 前回Dは3,000ステップ・初期100,000点、今回は12,000ステップ・初期180,000点です。メッシュ・教師・学習予算を同時に変えているため、差を概形修正だけの効果とは断定できません。
- 色と照明は教師画像に焼き込まれた外観です。Unityのライトによる動的な再照明まで対応したものではありません。
- 今回Unityアプリでの実読み込みは行っていません。
