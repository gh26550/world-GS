# 初期画像と統合メッシュの照合（2026-11-06）

既存200枚版の初期画像と統合メッシュを、初期画像専用カメラから比較した。新規の写真生成・GS学習・元メッシュ修正は行っていない。

```bash
./run.sh inspect-front runs/rgb200_20261105_production --output runs/front_inspection_new --orientation-probes
```

comparison.html：元画像・同一カメラのメッシュ・50%重ね合わせ・部位別の輪郭/面差分・本棚180度回転の診断用描画。
report.json：IoU、元マスクの被覆、予測輪郭の適合、重心ずれ、カメラ、元ファイルのハッシュ。

初期画像のカメラ行列はframes[0]の個別K（焦点距離530.524px、水平画角51.52度）を使用。メタデータ全体のK（333.626px）とは異なる。既存のGS学習もフレーム別Kを使用しており、この違いだけを過去の学習バグとは扱わない。

## 実画像から確認した問題
1. 左本棚は元の描画で板状の背面が手前に見える。位置と大きさを変えず180度だけ仮回転すると、棚板と開口が現れた。向きの誤りが含まれることを確認。回転は診断画像だけで、元のGLB・NPZ・計画は未変更。
2. 回転後の左本棚にも本はほぼない。向きと別に、復元形状・内容の不足がある。
3. ソファのSAM由来マスクにクッション部分の穴がある。低い適合率を根拠にメッシュを縮めると、マスク誤差へ合わせる危険がある。対象に含める部位を揃え、マスクを先に点検する。
4. 初期画像で見える側面窓・右の暖炉・植物は現在の統合メッシュに未反映。主要家具4点の外接矩形合わせだけでは、部屋全体の構図の一致は測れない。
5. 室内構造の見え方に差が残る。部屋寸法6x3x6mは推定で、実測ではない。既存カメラフィットにはeye_zの探索範囲端への到達警告がある。カメラだけが誤っていると断定はできず、部屋寸法・壁/天井の境界も併せて照合する必要がある。

## 修正の順序
まず家具マスクの対象範囲と前後方向を直してから、主要家具の位置・大きさ・遮蔽を再評価する。次に側面窓などの主要構造を反映し、壁・床・天井の投影線も使ってカメラと部屋寸法を見直す。一視点のマスクに合わせた非一様なメッシュ変形は今回行っていない。

この段階は照合と診断。既存画像200枚・統合メッシュ・PLYは変更せず、233カメラの既定も維持する。マスクや検出枠は推定であり、独立した3D正解ではない。テクスチャの色差は輪郭の誤差に混ぜて採点しない。
