# 照合修正と不足面を狙う再生成

この処理は初期参照画像を維持し、照合で判明した概形の誤りを修正したうえで、カメラごとの教師を作り直します。物体別の新規T2I画像は生成しません。

## 概形の修正

修正プランは初期画像と元メッシュのSHA-256に結び付けます。別のシーンに同じ回転を自動適用しません。

今回確認済みの修正：左本棚を中心周りに180度回転、中央窓を2列3段の格子に変更、ランダム生成していた窓外の枝を除去。初期画像の左窓と矛盾する部屋幅の仮定を見直し、家具を動かさず左壁をx=-3.0から約-2.399へ変更して開口を追加します。窓と室内寸法は画像からの仮説で、実測ではありません。

## 教師生成

- 追加233視点を維持し、通常視点の一部を家具の不足面に向けた家具別の専用視点へ置き換えます。
- 初期写真の画素は、共通メッシュの深度・遮蔽・物体IDが一致する箇所だけへ移します。床とラグなど、深度が近い別の面に混ぜません。
- 家具の観測済み画素を保持し、未観測領域をDepth/Canny ControlNetとIP-Adapterで補います。
- 壁・天井に写真断片を固定して三角形状の継ぎ目を作らないよう、構造面は生成対象にします。床・ラグの観測は初期画像を基準にし、後続写真の断片を無条件に重ねません。
- 各写真は深度境界とRGB境界で検査し、極端な近接や大きな見切れのカメラはRGB対象から外します。
- 家具を向いた候補を優先してRGB教師200枚を選びます。未達は未達として停止し、無理に合格にしません。

## 再実行

```bash
cd '/home/dpc7/world GS'
./run.sh regenerate-surfaces runs/rgb200_20261105_production \
  --output runs/surface_new \
  --correction-plan examples/corrections/livingroom-20261109.json \
  --previous runs/controlled_revision_v2_20261106 \
  --steps 12000 --max-points 180000
```

初期画像との照合だけ先に確認するときは`--prepare-only`を付けます。同じ出力で再実行すると、画像ハッシュを確認した決定済みの教師から再開します。別の画像・別のメッシュでは、そのシーンの照合結果に基づく修正プランが必要です。

`WORLDGS_KEEP_MODELS_ON_GPU=1`は任意の高速化です。GPUメモリーに余裕がない場合は指定せず、従来のモデル退避動作を使用します。

## 検証と限界

概形の正面描画、全教師画像、RGB採否、最終PLY、GSの正面・多視点描画を保存します。保持画素が実際に同一であること、別の物体へ画素を移さないことをテストします。深度境界の合格は家具の同一性や実写品質の保証ではないため、教師とGSの目視確認を併用します。元画像に写る全ての小物・暖炉などを立体化する処理までは含みません。

前回の比較は3,000ステップ・初期100,000点、今回の本生成は12,000ステップ・初期180,000点です。メッシュも変更するため、前回との差を概形修正だけの効果とは断定しません。


`--previous`を指定すると、証拠の最終確認、安全な不合格視点の再試行、最大3回の代替カメラ補完、本学習、前回と同じ8カメラの評価まで進みます。教師200枚に達しない場合は未達として停止します。保持画素により2D配置を確認できる境界と、深度推定の不一致は別に記録し、未知領域の深度誤りを無条件には救済しません。

最終学習前には、メッシュ・初期点群・全教師画像・カメラ・学習設定を署名に記録します。教師や設定が変わった場合は古い学習結果をそのまま再利用しません。
