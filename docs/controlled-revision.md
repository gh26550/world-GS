# 教師画像・カメラ・GS学習の制御比較

初期参照画像と統合メッシュは変更せず、次の3段階を別出力で実施します。

## 2. 多視点教師画像

- カメラ回転だけで参照画像を選ばず、共有メッシュ上で対応する面が双方から見えるかを検査します。
- 対応点を既存写真に投影し、深度が整合する画素だけを外観ガイドへ移します。遮蔽・画面外・境界の画素は使用しません。
- 高周波の木目合わせを目的とせず、大まかな色や材質を引き継ぎます。境界と深度のガイドはメッシュ由来です。
- 問題の強い16視点をローカルControlNetで再生成。変更量を抑え、元の家具配置を優先します。採否と旧新画像はreview.htmlに残します。
- 深度境界の検査は家具の同一性を証明しません。再生成の失敗は採用せず、元の証拠も保持します。

## 3. カメラ・深度判定

- 233視点の計画を維持。極端な近接、近距離での大きな見切れを検査し、画角と注視方向の改善を試します。
- 十分な距離での部分的な見切れを一律に禁止しません。
- 実際のメッシュ深度差が小さい境界は、推定深度に段差が出ることを強制せずRGB境界も用います。
- 画像端と少なすぎる境界は判定根拠から外します。証拠不足を自動合格にはしません。
- 深度とRGBの両方に有効な証拠があるときは、RGBの模様だけで家具の深度不一致を救済しません。
- 不適切な写真はRGB教師から除外し、メッシュの形状監督のみ使用します。200枚は目標で、未達を黙って埋めません。

## 4. 2×2比較

| 条件 | 教師 | RGB損失 |
|---|---|---|
| A | 既存 | 従来のL1 |
| B | 修正 | 従来のL1 |
| C | 既存 | 対数型の頑健な損失 |
| D | 修正 | 対数型の頑健な損失 |

- 全条件で初期点群ファイル、乱数、初期点数上限100,000、3,000ステップ、深度・形状・被覆の重みを共通にします。
- 対数型RGB損失：s log(1 + |予測−教師|/s)、s=0.12。大きな色差の勾配を弱めます。位置や不透明度は固定しません。
- A/BとC/Dは教師変更、A/CとB/DはRGB損失変更の効果を比較します。
- 233の教師カメラとは別の共通評価カメラを生成し、すべての条件で同じ軌跡を使います。
- メッシュへの深度AbsRel、MAE、RMSEと欠損率、視点間深度再投影を記録します。これは生成メッシュ準拠の検査で、実世界の正解への一致ではありません。
- 未学習視点の正解写真がないためPSNRやSSIMを精度として報告しません。CLIP-IQA+、Aesthetic、人による評価はこの比較コマンドでは未実施です。
- WorldMeshの指標体系を参考にしますが、再投影のマスク・尺度などは本実装の定義であり、論文表の数値との直接比較はできません。

## Ubuntuで再実行

```bash
cd '/home/dpc7/world GS'
./run.sh compare-revision runs/rgb200_20261105_production \
  --output runs/controlled_revision_new \
  --steps 3000 --max-points 100000 --regenerate 16
```

各条件にscene_unity.ply、gaussians.npz、未学習視点の描画、training.jsonを保存します。

比較用の元データは保持します。初期メッシュの向き・小物不足がある場合、その限界は後段へ残ります。


## 家具の同一性と確認の記録

新規写真はGrounding DINOで種類・位置・大きさも確認します。検出器は平坦な壁を家具と誤認したり、家具の背面を認識できなかったりするため、検出失敗を画像の破綻と同一視しません。曖昧な結果は画像ハッシュ付きvisual_review.jsonに目視確認を記録できます。明確にテーブルが座面へ変わるなどの例は、深度検査に合格していても除外します。semantic_review.jsonで機械判定と目視判断を区別します。

今回の新しい画像は16枚を試し、形状・カメラの検査後の6枚を追加確認しました。1枚は家具の取り違えとして除外。5枚が最終候補で、そのうち4枚を200枚のRGB教師に含め、残り1枚は枚数上限のため形状監督のみとしました。旧新の教師差は再生成だけでなく、採否の見直しも含みます。

比較では目的関数が異なるため、学習ログのRGB損失値をそのまま優劣判定に使いません。共通の評価カメラからの描画と深度・欠損率を比較します。
