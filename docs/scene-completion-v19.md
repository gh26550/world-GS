# 元画像・配置を維持するシーン完成処理 v19

v17の構成（共通配置、領域別生成、配置検査、GSの局所形状自由度）を維持し、実画像で確認された認識の曖昧さを扱う。

- 元画像のSAM物体マスクと、独立して一致した親物体がある場合に限り、同じ物体内の部分検出を記録する。ソファの部分がchairと呼ばれても、親ソファが欠けた画像や、別の場所のchairを免除しない。
- 全体画像の検出に加え、予想される各物体領域を切り出して期待カテゴリを再確認する。対象の位置や寸法の許容範囲は変更しない。全体検出と切り出し検出の分類不一致は記録する。
- 既に対応した物体群に検出矩形の65%以上が重なる重複・集合的認識は、追加物体の証拠と区別する。対象物体が未確認の場合、または領域外への家具の生成は不採用。これは物体数の独立した正解を保証するものではなく、認識の曖昧さを明示する処理。
- 画像の0.5%未満（最低256画素）の物体領域は新しく生成せず、共通メッシュからの描画を保持する。判別できない微小部分を推定画像で置き換えない。
- 建築材の切り出しに含まれた家具模様が別視点で増殖しないよう、構造面ガイドを材質の代表色へ戻してから、元画像の可視・非遮蔽部分を参照する。家具の画像領域を壁や床へ誤投影しない。
- 家具ごとの元画像由来の切り出しも外観条件として使う。独立した物体T2I画像へ置き換えない。

本生成: 既存scaffoldを入力に`synthesize-appearance`、全視点検査後に`train --steps 3000 --max-points 180000`を実行する。元の初期画像・メッシュ・3D配置は変更しない。新しい出力先を使用する。

判定は検出器・深度推定の誤差を含むため、完成後のGS実描画を別途確認する。被覆検査の合格と、写実性や配置の完全一致は区別して報告する。
