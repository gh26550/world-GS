# 参照生成経路の再構築（2026-11-05）

## 目的と構成
初期画像の構図・家具配置を保つ共通メッシュを基準に、カメラごとの写真を生成し、その写真を3DGSの教師にする。物体別の教師画像生成は行わない。画像からのSAM3Dメッシュ復元用切り出しは継続する。

モデル環境、正面画像、基準メッシュ、GS学習・Unity出力を再利用し、参照生成と採否判定を分離した。新しいroom-localの既定は正面・左・右・背面の4視点実験。34視点の旧経路は互換用に残す。4視点は全周完成を意味しない。

1. 共通メッシュと固定カメラからRGB・深度・境界を描画。
2. ローカルのSD1.5 inpainting + depth/canny ControlNet + IP-Adapterでカメラごとの写真候補を生成。DepthProで推定深度を取得。
3. 候補を全カメラ分保存。一つの不合格で残りの収集を中断しない。標準2候補、最大3候補で打ち切る。
4. 画像生成器から独立した幾何評価。全体の深度境界と、共通メッシュの物理グループ単位の外形を検査。別々の窓部品などを独立した家具として扱わない。
5. 全視点合格時だけ学習データをまとめ、GSへ進む。不合格はreview_requiredとして保存。

物体検出器のラベル、家具名別の除外規則は採否に使用しない。推定器が概形RGBでも検出できる境界には深度の一致率0.55以上、検出できない境界にはRGBの一致率0.60以上を要求する。距離許容は512画素時10画素。旧スコアも保存し、閾値を変えて合格扱いにしない。保存画像・深度・カメラ・メッシュのハッシュを学習前に確認する。

## 実行
```bash
cd '/home/dpc7/world GS'
./run.sh reference-run runs/dual_input_v24_scaffold_20261104 --output runs/reference_new --attempts 2 --model controlnet --train-steps 1000
# 保存した同じ画像を、生成せずに独立した出力先で再評価
./run.sh reference-evaluate runs/reference_new --output runs/reference_rechecked
```

新しい正面画像・概形から始める場合はgenerate --mode room-localを使う。参照生成は上記の新経路へ接続済み。既存フォルダを別要求で上書きしない。

## 今回の実測
同じ初期画像・家具配置・カメラを使用。初期画像と概形は作り直していない。

- ControlNet、2候補：全4視点を収集、物理グループ評価で3/4合格。
- ControlNet、最大3候補：左だけ追加生成、3/4合格。左の窓付近の深度境界が未達。GS学習は実行しなかった。
- FLUX Base、2候補：比較実験では旧部品単位評価で1/4合格。評価粒度が異なるため正式な同条件モデル順位ではない。今回の新既定には採用していない。

166件の単体テストが成功。家具欠落・大きな視点変化の棄却、全視点収集、不合格時に学習データを出さないことを含む。これらは実シーンの品質保証ではない。

## 出力と限界
review.htmlが概形と採用候補の一覧。references/<camera>/に全候補画像、推定深度、元のメッシュ深度、判定と根拠のハッシュを保存する。experiment.jsonはカメラ・モデル・試行条件、assessment.jsonは全視点の結果。

幾何検査だけでは家具の同一性・余分な物体・材質の正しさを保証できず、模様のエッジが一致と誤判定される場合もある。正面1枚から復元した概形の裏側・小物の不足はこの変更では解決していない。メッシュ描画を使う評価視点は独立した正解写真ではない。Unityの動的再照明も未対応。

次段階は、残る左視点について写真の推定深度と基準メッシュ深度のどちらが不適切かを確認すること。今回の結果を全周生成成功や完成GSとして扱わない。
