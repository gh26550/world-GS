# 二画像条件での写真参照・GS生成 v24（2026-11-04）

## 変更の目的

v21は初期写真を粗い形状に投影し、背景を固定したため、本棚の側面や壁に正面の像が残った。v24は配置を指定する概形ガイドと、外観を指定する初期写真を別入力にする。新規視点に元画像の画素をコピーしない。

今回の初期画像と4家具の配置はv21から維持する。初期画像を新しく生成し直した比較ではない。プロンプトは次のとおり。

> A cozy living room with a brown leather sofa, two bookshelves filled with books, a wooden coffee table, a rug, warm daylight

## 処理

1. 初期写真の窓・ラグをGrounding DINOで検出する。初期カメラから背面壁・床へのレイ交差で概形を追加する。窓は既存の開口・窓枠生成を使い、ラグは床直上の薄い形状とする。床全面をラグ材質にしていた記述を木床へ訂正する。
2. 共有概形から、各家具の離れた2視点と全周4方向のガイドを描画する。ガイドには初期画像を再投影しない。
3. 内蔵image_genに「画像1＝カメラ・配置・向き・輪郭・遮蔽」「画像2＝家具の同一性・材質・色・採光」を指定する。12枚を新規生成。生画像・指示全文・カメラ・ガイド・画像のハッシュを保存する。
4. 画像は1:1のまま512×512へPillow BOXで縮小する。切り抜き・縦横比変更・色正規化を行わない。
5. 物体のクラス・位置・大きさ、深度境界、構造面の平面性を検査する。分類器の誤認識は、ガイドと生画像を個別に目視比較し、理由と双方のハッシュを記録した場合だけ配置判定を補う。自動判定結果自体は書き換えない。深度検査の不合格は目視レビューで上書きしない。
6. 新規11枚と初期画像1枚をRGB教師とする。残りの概形視点はRGB損失0で、深度・被覆だけを学習する。写真3回対形状専用1回の配分で3000ステップ学習する。未写真化面の初期色は概形の仮色であり、写実的な裏面を復元したという意味ではない。

今回、dual_08は深度境界recall 0.227、構造面誤差0.450で不採用。配置の自動判定が通った新規写真は4枚。残る7枚は部分的な本棚・ラグ・空白壁の誤認識を目視比較で補った。これは完全自動で多視点整合を証明した結果ではない。

## 再実行

```bash
./run.sh complete-proxy runs/fresh_room_v20_20261104_scaffold --output runs/new_proxy
./run.sh prepare-photographs runs/new_proxy --output runs/new_photo_inputs
# manifest_template.jsonの各ガイドと初期画像を二入力として画像生成する。
# raw_path/providerを記入し、必要な個別レビューは生画像・ガイドのSHAで紐づける。
./run.sh import-photographs runs/new_proxy --manifest /absolute/path/manifest.json --output runs/new_gs
./run.sh train runs/new_gs --steps 3000 --max-points 180000
```

image_genはこのチャットの内蔵ツールで呼ぶ。ローカルCLIが内蔵ツールを直接呼ぶ完全自動API実装ではない。既定のphoto-roomは互換用v21経路のままで、v24の再実行には上の手順を使う。ローカルControlNetで全画面を生成する比較用`--whole-view`も追加したが、今回は質感不足のため最終教師に採用していない。

## 出力と検証

- WSL: `runs/dual_input_v24b_20261104`
- 初期画像を補った概形: `runs/dual_input_v24_scaffold_20261104/scene_mesh.glb`
- 学習後GS: `scene_unity.ply`（binary little-endian）、234,767 Gaussians
- 写真教師: `source_teacher.png`、`dual_*.png`
- 写真の生画像・ガイド: `raw/`、`guides/`
- 個別検査・生成指示・前処理: `external_reference_audit.json`
- 形状専用教師: `geometry_only_*.png`。カメラ・深度・面IDはscene.jsonに紐づく。
- テスト142件通過。平面交差の再投影、ラグの厚さ、教師改変の拒否、写真と形状の学習配分を含む。
- 評価用4視点は概形の幾何プローブ。独立した写真の正解ではないのでRGB L1を精度指標として出さない。

## 残る制限

窓は背面壁にあるという仮定を置く。検出矩形から作る窓・ラグは概形であり、厳密な領域復元ではない。家具メッシュの正面シルエット平均IoUは元の約0.578から改善していない。家具の向き・奥行きが画像を十分に説明していると保証できない。植物・小物は独立した概形が不足する。生成写真の陰影・窓外・局所形状は視点間で変化する。GSにはぼけ・壁の色むら・遮蔽境界の誤差が残り得る。照明は画像に焼き込まれ、Unityの動的照明へ対応する実装ではない。
